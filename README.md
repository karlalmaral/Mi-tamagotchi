# Mi-tamagotchi
# 🐣 Tamagotchi en Python

## 📖 Descripción
Este proyecto es un Tamagotchi virtual desarrollado en Python, donde el usuario debe cuidar una mascota digital realizando diferentes acciones para mantenerla sana y feliz.  

El programa fue creado con el objetivo de practicar lógica de programación y el uso de estructuras básicas de Python.

---

## 🚀 Características
- Alimentar a la mascota 🍎  
- Jugar con la mascota 🎮  
- Dormir a la mascota 😴  
- Mostrar su estado actual 📊  
- Sistema de hambre, energía y felicidad ❤️  

---

## 🛠️ Tecnologías Utilizadas
- Python 3  
- Consola / Terminal  

---

## ▶️ Instalación y Uso

1. Clona este repositorio:
bash git clone https://github.com/tu-usuario/tu-repositorio.git 

2. Entra a la carpeta del proyecto:
bash cd tu-repositorio 

3. Ejecuta el programa:
bash python tamagotchi.py 

---

## 📸 Vista Previa
Al iniciar el programa aparecerá un menú interactivo con opciones para cuidar a tu mascota.
